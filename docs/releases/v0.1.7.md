- **Porters' own catalogs.** Mixtape can now list ports that porters host on their own websites, not just GitHub releases. Their games install and update with one button like everything else, and a damaged download is refused before anything changes. Updates unzip over the existing folders, so saves, settings and save states are never touched.
- **Miyoo64 by mr-finster** is the first: nine native N64 ports built from the decompilations (Mario Kart 64, Diddy Kong Racing, Ocarina of Time, GoldenEye 007, F-Zero X, Star Fox 64, Paper Mario, Super Smash Bros. and Super Mario 64). You need your own ROMs. His Mario Kart 64 is listed as **Mario Kart 64 (Miyoo64)**, because another port already uses that name.
- **For porters:** publish a catalog file and open an [Add my catalog](https://github.com/snyderman3000/mixtape/issues/new?template=add-catalog.yml) issue. The list of catalogs lives in the Mixtape repo, so new ones appear without a Mixtape update. The format is in the README under "Publishing your own catalog".
- `config.json` has a new `sources` setting for adding catalogs to your own card.
