- **Projects beyond the community catalog.** Mixtape now also lists ports from its own list, [`catalog/extra.json`](https://github.com/snyderman3000/mixtape/blob/main/catalog/extra.json), alongside the MiyooMini-Ports catalog. First up: [Panel Attack](https://github.com/snyderman3000/panelattack-miyoo), with online play. If the community catalog adds the same project later, its entry is used instead.
- **Mixtape updates itself.** It checks its GitHub releases at startup and shows **▲ READY · SELECT** in the header when a new version is out. Press SELECT to install it; your settings are kept and Mixtape restarts.

Updating from 0.1.1: install this version by hand once (copy the `App` folder over the old one). Future versions can be installed from inside Mixtape.
