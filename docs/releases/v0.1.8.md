- **Updates on open.** Mixtape now checks what it installed when you open it. If something has a new version, an **UPDATES READY** window lists it with the old and new version numbers. Press A to open one and update it, or B to close the window. Each new version is announced once, and it stays marked **▲UPD** in the list until you update. If the NEW ARRIVALS window is showing, the updates window waits until you close it.
- The check doesn't slow down startup or use up GitHub's lookup allowance: it runs in the background, and GitHub projects are checked at most once an hour. Y still checks everything right away.
