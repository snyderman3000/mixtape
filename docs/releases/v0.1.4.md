- Pressing SELECT (or Y) now always asks GitHub for the latest releases. Before, if that check failed, for example because of GitHub's hourly limit for anonymous lookups, Mixtape quietly used its saved copy from earlier and could say "up to date" when a newer version existed. Now it tells you the check didn't go through.
- Failed release lookups are written to `data/mixtape.log`.

If you're seeing GitHub's hourly limit often, add a free GitHub token as `github_token` in `App/Mixtape/data/config.json` (no permissions needed).
