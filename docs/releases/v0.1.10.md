- **A Mixtape theme for OnionOS.** Mixtape now carries a matching theme: amber phosphor on black, scanlines and the amber/magenta/cyan tape stripes, with a cassette on the Games tile, amber highlight bars in every list, LED-meter brightness and a tape-reel charging animation. Press SELECT, choose **Install Mixtape theme**, then pick **Mixtape** in Apps → Theme Switcher. It keeps OnionOS's layout and your icon pack. Later Mixtape updates offer **Update Mixtape theme**, and **Remove Mixtape theme** deletes it. It's also attached below as `Mixtape-Theme-v0.1.10.zip` for copying to the card by hand.
- **Mixtape in Games (optional).** Turn on **Mixtape in Games list** in the SELECT menu and Mixtape shows up in Games as its own system, so you can add it to Favorites and open it from the home screen. It's off until you turn it on, and turning it off removes it again.
- **Sort the HOMEBREW tab.** Y now switches the order: newest additions, A–Z, release date, or shuffled. (Homebrew Hub doesn't keep download counts or ratings, so there's no "most popular".) Syncing with Homebrew Hub moved to the SELECT menu.
- **Fixed:** the full Homebrew Hub sync could miss some games, because Mixtape used parameter names from Homebrew Hub's docs that its API ignores. It now pages through the list in a stable order, 50 at a time, and fetches the list once more after updating to catch anything missed.
- SELECT now opens a small Mixtape menu; updating Mixtape itself is in there too.
