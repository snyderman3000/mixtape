- **Erase can now clean up after an app.** If an app ships a `mixtape-uninstall.sh`, Mixtape runs it before erasing the app's files, so the app can undo changes it made outside its own folder. MiniAmp 0.2.1 uses this to put OnionOS's original sound library back when you erase it. If the script fails, the files are still erased and Mixtape shows what went wrong.
