- **Fixed installs that grabbed the wrong release file.** Some projects publish source-code bundles next to their app, and a bundle with "miyoo" in its name could outrank the real build. Mixtape now prefers files named after the project and skips pinned dependency bundles (names carrying a commit hash). This fixes **Miyoo Better Favorites**, which failed with "unrecognised archive layout."
- **Miyoo Better Favorites** installs to Apps. For the Home Favorites tile and GameSwitcher return, run its computer installer from the project page; Mixtape shows a reminder after install.
